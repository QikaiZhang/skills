# mobile-flutter

Flutter / Dart 客户端开发相关 Skill 集合。用于纯 AI 开发 Flutter 移动端、平板端、桌面端客户端时，约束架构、布局、路由、数据层和测试质量。

## Flutter Skills

| 目录 | 来源 | 用途 |
| --- | --- | --- |
| [flutter-apply-architecture-best-practices](./flutter-apply-architecture-best-practices/) | `flutter/agent-plugins@flutter-apply-architecture-best-practices` | 按 UI / Logic / Data 分层组织 Flutter 应用，适合新项目和重构。 |
| [flutter-build-responsive-layout](./flutter-build-responsive-layout/) | `flutter/agent-plugins@flutter-build-responsive-layout` | 使用 `LayoutBuilder`、`MediaQuery`、`Expanded` / `Flexible` 做移动端、平板、桌面自适应布局。 |
| [flutter-fix-layout-issues](./flutter-fix-layout-issues/) | `flutter/agent-plugins@flutter-fix-layout-issues` | 排查 overflow、constraint、scroll、尺寸异常等 Flutter 布局问题。 |
| [flutter-setup-declarative-routing](./flutter-setup-declarative-routing/) | `flutter/agent-plugins@flutter-setup-declarative-routing` | 配置声明式路由，适合页面流、深链、多端导航。 |
| [flutter-implement-json-serialization](./flutter-implement-json-serialization/) | `flutter/agent-plugins@flutter-implement-json-serialization` | 实现 JSON 序列化、API model、代码生成。 |
| [flutter-use-http-package](./flutter-use-http-package/) | `flutter/agent-plugins@flutter-use-http-package` | 使用 Dart / Flutter HTTP 能力接入服务端接口。 |
| [flutter-add-widget-test](./flutter-add-widget-test/) | `flutter/agent-plugins@flutter-add-widget-test` | 添加 Widget 测试，验证组件渲染和交互。 |
| [flutter-add-integration-test](./flutter-add-integration-test/) | `flutter/agent-plugins@flutter-add-integration-test` | 添加集成测试，验证端到端用户流程。 |
